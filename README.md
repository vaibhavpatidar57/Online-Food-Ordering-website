# 🍽️ Online Food Ordering Website

This project is a dynamic food ordering system built using **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript**.

## 🔧 Features
- User panel for browsing and ordering food items
- Admin panel to manage menu, orders, and customers
- Secure database connection with MySQL
- Order confirmation and management system

## 🧠 Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: PHP, MySQL  
- Server: XAMPP (Apache, MySQL)

## 📂 How to Run
1. Copy project files to your XAMPP `htdocs` folder.  
2. Import `food.sql` into phpMyAdmin.  
3. Run the project at `http://localhost/Online-Food-Ordering-website/`.
